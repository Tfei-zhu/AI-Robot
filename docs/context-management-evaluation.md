## 综合评测口径

A为最近6轮基线；B增加工具投影和证据复用；C增加按额度选历史；D增加早期摘要。固定30条脚本，20开发/10留出，各重复3次；10/30/60轮均覆盖。每组独立生成全部模型回答，禁用答案语义缓存，工具返回固定资料。

同模型、采样参数、输出上限、并发数和预算，记录数据及被测源文件哈希。摘要、重试和工具调用产生的模型用量全部计入，不把流式事件数当Token；金额未知不能记为0。金额为公开单价估算，不代表账单。

终局检查语言、版本、依赖和任务编号；检索当轮检查250ms尾部证据是否用于回答；普通约束检查要求不超过30字的回复。固定语料下的约束恢复任务不能代表任意工程任务完成率。知识更新、实时文章数据、Go修复及取消/隔离另外通过压力与机制测试验证。

## 已发现并修复

1. 摘要遗漏旧有效约束、模型重试未收到校验反馈。
2. 用户纠正后，旧版本被保护规则重新加入有效列表。
3. 首次摘要不存在旧约束，以及历史纠正跨摘要延续时被错误拒绝。
4. 模型为非约束信息生成无效替代关联，阻断安全摘要；关联现在仅能作用于已有有效约束。
5. 首轮语义缓存阶段取消未统一清理计量记录。
6. 原来仅保留最新摘要；现在归档每个成功提交的有效版本。

失败数据保留于 `final/`、`final-v2/` 至 `final-v6/`，均不得当作最终通过证据。修复后先通过专项测试和真实开发样本再重新冻结。最终 `final-v7/` 中，D组归位替代关系和修复反馈前的失败记录单独保留。

历史final-v7的A/B/C与D仅摘要专用分支版本不同：A/B/C关闭摘要，在首个条件直接返回。对冻结源文件与新版本的语法树检查确认导入、全局状态、公共函数、函数签名及首个条件相同；其他所有被测文件哈希必须相同。该轮比较器需要显式传入冻结源文件执行验证，报告保留真实哈希及适用范围，不直接忽略差异。当前final-restored-v3四组代码完全一致，不使用此历史例外。

网络失败未返回用量时，实际用量和金额保持未知；评测预算扣减请求前预留的保守上界，避免未知尝试绕过额度。此估算只用于限额保护，不能填入实际用量或用来通过成本门槛。未知尝试和未完成任务均保留。
